# SEHATLINK Prototype — Fixed

Open `index.html` directly in Chrome/Edge. No Node.js, npm, server, or internet is required.

Demo flow:
1. Frontline Worker → Dashboard → Open Meena case
2. Triage → Run assisted triage → Send to doctor queue
3. Switch Doctor → Doctor Queue → Review case
4. Create referral & care plan
5. Referrals → Advance status through Created → Scheduled → Visited → Completed
6. Follow-up → demonstrate overdue outreach
7. Switch Administrator → System Overview / Facilities / Quality Analytics

All patient information is fictional demo data. Assisted triage is decision support, not diagnosis.
